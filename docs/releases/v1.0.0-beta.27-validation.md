# Validação da Beta 27

## Causa confirmada e correção
A preferência de movimento reduzido do Windows estava ativa neste computador. Avatar usava a mesma variável para congelar a imagem de perfil e selecionar a versão estática da moldura. A prova nativa anterior carregou /static apesar de showDecoration estar ativo. O catálogo e a resposta de produção contêm APNG original de 60 frames; a extensão .png não representa uma imagem estática.

AvatarDecoration agora decodifica a mídia original por ImageDecoder no Electron/Chromium. A atividade real de áudio já coletada pelo SpeakingDetector determina a reprodução e mantém a histerese de 250 ms existente. A moldura permanece no último frame no silêncio. Após 1,5 s sem reprodução, o decoder fecha, mantendo apenas a imagem pintada e os bytes compactados para retomar. Fechar o perfil cancela o carregamento e todos os timers e libera o decoder. Outros navegadores têm fallback para a mídia original ao animar e o asset estático no silêncio.

## Execução nativa comprovada
O script packages/desktop/scripts/avatar-animation-smoke.cjs abriu o Electron 43.4.0 com os componentes React reais e dois APNGs originais do catálogo local. Confirmou mudança de pixels para ambos, frames idênticos após pausar, contador de decode sem incremento no silêncio, zero decoders abertos após a pausa, retomada e desmontagem do perfil. A preferência do Windows continuou em movimento reduzido. O teste não usou animação CSS nem vídeo simulando chamada.

O renderer isolado usou aproximadamente 109 MiB de working set no momento da medição. Essa amostra curta não comprova ausência de vazamento em uso prolongado nem representa todo o aplicativo com uma chamada ativa.

## Atualizador
A fonte é GitHub/talismanbruno/lumesync, fixada no processo principal. electron-updater compara SemVer sem downgrade e aceita os pre-releases beta; o catálogo de release deve conter beta.yml/latest.yml, instalador NSIS e blockmap. Downloads só começam após validar versão superior e nomes/hashes dos arquivos. O downloader verifica SHA-512. Instalação automática ao sair está desabilitada; Atualizar e reiniciar chama quitAndInstall(true, true), bloqueado durante chamadas. NSIS preserva o diretório de dados e solicita a reabertura. O watchdog que poderia iniciar a versão antiga foi removido.

## Limites de comprovação
As suítes de interface usam mocks para eventos de voz e atualização. O teste nativo é de reprodução de assets reais, não uma chamada entre contas. Nesta execução, os auxiliares de interface do Windows falharam na inicialização; por isso não há comprovação de chamada real entre duas contas, captura física de câmera/microfone, revisão visual completa da instalação existente ou upgrade real com preservação de uma sessão autenticada. macOS e Linux seguem com download manual. A publicação e disponibilidade de arquivos devem ser verificadas separadamente no GitHub e não transformam testes com mocks em prova de instalação.
