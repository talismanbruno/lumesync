# Lume

Lume is an independent communication product built on the open-source Backspace
codebase. This fork has its own name, visual identity, icons, and product direction.

The upstream project remains credited in `NOTICE` and its source code continues to
be distributed under the GNU Affero General Public License v3.0. The Backspace name,
logo, and original application icons are not used as Lume branding.
